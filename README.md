# Schoolplannenarchief Nederlands voortgezet onderwijs

Dit openbare archief bevat de lokaal veiliggestelde schoolplannen die gebruikt
worden door het [landelijke schoolplannenoverzicht](https://moorlag.github.io/schoolplannen/).

## Inhoud

- **387 actuele plannen** in de release
  [Actuele VO-schoolplannen – 28 oktober 2026](https://github.com/moorlag/schoolplannen-archief/releases/tag/actueel-2026-10-28)
- **197 verlopen of niet als actueel bevestigde fallbackplannen** in de release
  [Verlopen VO-schoolplannen – fallbackarchief](https://github.com/moorlag/schoolplannen-archief/releases/tag/verlopen-2026-10-28)
- **584 plannen in totaal**, steeds één best beschikbare versie per gedekte school
- **67 scholen zonder lokaal opgeslagen schoolplan** op het meetmoment

De bestanden staan afzonderlijk als releasebestand op GitHub. Daardoor kunnen
ze per school worden geopend zonder de technische repository zelf onnodig groot
te maken.

## Catalogus

- [`manifest.csv`](manifest.csv) — geschikt voor Excel en gegevensanalyse
- [`manifest.json`](manifest.json) — geschikt voor websites en scripts

Per school vermeldt de catalogus onder meer BRIN, schoolnaam, plaats, provincie,
regio, status, planperiode, GitHub-link en de oorspronkelijke officiële bron.

## Belangrijke kanttekening

De officiële publicatie van de school of het schoolbestuur blijft leidend. Een
bestand in het verlopen archief is alleen opgenomen als er nog geen nieuwere,
gecontroleerde versie beschikbaar was. De collectie wordt daarom periodiek
opnieuw gecontroleerd.
